# Инструкция по установке, сборке и запуску EchoMesh Windows

В данном руководстве подробно описан процесс развертывания, локального запуска и создания автономного инсталлятора для клиента **`echomesh-windows`** на платформе Windows 10 / 11.

---

## 1. Системные требования

- **Операционная система:** Windows 10 (версия 1809+) или Windows 11 (рекомендуется для полноценного эффекта Mica).
- **Архитектура:** `x86_64` (64-бит).
- **Компоненты ОС:** Microsoft Edge WebView2 Runtime (встроен в Windows 11 и актуальные версии Windows 10).
- **Инструменты разработчика:**
  - [Node.js](https://nodejs.org/) (версия 18 LTS, 20 LTS или новее).
  - [Rust](https://rustup.rs/) (инструментарий `stable-x86_64-pc-windows-msvc`).
  - [Visual Studio Build Tools 2022](https://visualstudio.microsoft.com/visual-cpp-build-tools/) с компонентом «Desktop development with C++» (C++ CMake tools, MSVC v143, Windows 10/11 SDK).

---

## 2. Подготовка окружения на Windows

### Шаг 1: Установка Node.js
Если Node.js еще не установлен, выполните команду в PowerShell от имени администратора:
```powershell
winget install OpenJS.NodeJS.LTS
```
Или скачайте установщик с официального сайта [nodejs.org](https://nodejs.org/).

### Шаг 2: Установка Rust
1. Скачайте `rustup-init.exe` с [rustup.rs](https://rustup.rs/).
2. Запустите установщик и выберите стандартную установку (вариант `1`).
3. Убедитесь, что выбран таргет `x86_64-pc-windows-msvc`:
   ```powershell
   rustup default stable-x86_64-pc-windows-msvc
   ```

### Шаг 3: Установка C++ Build Tools
Для компиляции нативных библиотек Rust на Windows необходимы библиотеки MSVC и Windows SDK:
```powershell
winget install Microsoft.VisualStudio.2022.BuildTools --override "--passive --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended"
```

---

## 3. Клонирование репозитория и установка зависимостей

1. Клонируйте репозиторий проекта:
   ```bash
   git clone https://github.com/denxxy/echomesh-windows.git
   cd echomesh-windows
   ```

2. Установите зависимости интерфейса (React, Fluent UI v9, Tauri API):
   ```bash
   npm install
   ```

---

## 4. Запуск в режиме разработки (Live Dev)

Для запуска клиента с горячей перезагрузкой интерфейса (HMR) и нативным бэкендом Tauri выполните:

```bash
npm run tauri dev
```

При первом запуске Tauri автоматически соберет бэкенд на Rust (`src-tauri`), запустит локальный Vite dev-сервер и откроет нативное окно Windows 11 с эффектом Mica.

---

## 5. Сборка автономного установщика (.exe / .msi)

Для компиляции оптимизированного релизного дистрибутива выполните команду:

```bash
cargo tauri build --target x86_64-pc-windows-msvc
```
*(Либо через npm-скрипт: `npx tauri build`)*

### Где найти готовый дистрибутив:
- **Автономный инсталлятор NSIS (.exe):**
  `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis/EchoMesh_0.1.0_x64-setup.exe`
- **Пакет установщика Windows Installer (.msi):**
  `src-tauri/target/x86_64-pc-windows-msvc/release/bundle/msi/EchoMesh_0.1.0_x64_en-US.msi`

Инсталлятор не требует предварительно установленного Node.js или Rust у конечного пользователя и готов к распространению.

## 6. Проверка сетевого соединения и эхо-тест

По умолчанию клиент настроен на подключение к официальному релею:
- **Адрес релея:** `77.81.5.109:8443`
- **Протокол:** Noise NK + маскировка под TLS 1.3 ClientHello (Pseudo-TLS).
- **Размер кадров:** строго 1420 байт с выравнивающим паддингом.

### Быстрое тестирование через Echo Node:
1. При запуске статус в боковой панели автоматически изменится на **«В сети»** (зеленый индикатор).
2. В списке диалогов выберите **Echo Relay Node (`[0xEE; 32]`)**.
3. Используйте быстрые чипы под полем ввода:
   - **`[Ping]`** — отправляет тестовое сообщение `PING`. Релей мгновенно возвращает зеркальный ответ с фиксацией времени доставки (RTT в мс).
   - **`[Noise Payload]`** — отправляет случайную криптографическую полезную нагрузку.
   - **`[1420b Test]`** — отправляет кадр с максимальной полезной нагрузкой 1394 байта (1420 байт с учетом 26-байтного заголовка протокола).

## 7. Особенности интеграции с Windows Shell

- **Системный трей (System Tray):** При нажатии на кнопку закрытия окна («X») приложение не завершается, а плавно сворачивается в область уведомлений Windows (трей). Для разворачивания кликните по иконке трея или выберите пункт «Открыть EchoMesh».
- **Нативные уведомления (Toasts):** При получении сообщений в фоновом режиме Windows 10/11 отображает системное всплывающее уведомление в Центре действий.
- **Хранение данных:** База данных SQLite сохраняется по системному пути `%APPDATA%\EchoMesh\echomesh.db`.
